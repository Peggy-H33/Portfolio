## Selected system

- Pattern: A，edge thesis + chaptered immersion。
- Why it preserves the locked Hero contract: Hero video absolute inset 0，覆盖整个 100svh；文案仅占左侧负空间，没有独立卡片或视频窗口。
- Alignment reason: 酒店空间与江景在右侧形成主视觉，中文标题沿左边缘下沉，与灯光水平线对齐；非 Hero 章节交替左右以避免全页居中。
- Section rhythm: 100vh 沉浸 → 骨白安静宣言 → 95vh 江岸 → 110vh 里弄 → 95vh 仪式微距 → 紧凑选择轨 → 深色行动收束。
- Layer contract: media 0 / scrim 1 / content 2 / nav 10 / dialog 100。
- Mobile transformations: Hero 保留 100svh 大画面，标题上移并缩为三行；章节从错列网格变为媒体先、文字后；时间轨横向滚动；不把 Hero 视频降为下半屏。
