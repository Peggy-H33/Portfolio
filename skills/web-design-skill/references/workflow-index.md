# Workflow index

Use this file as the routing layer. Finish and persist one stage before loading the next discipline. Re-open earlier decisions only when a later conflict proves they are invalid.

## Stage gates

| Gate | Required evidence | Pass condition |
|---|---|---|
| Brief | subject, audience, page job, content confidence, visual priority | Hero media mode and any regression baseline are explicit |
| References | observations separated from inference | at least 2 transferable rules per relevant reference |
| Type | 3 visible candidates per planned surface inside the real page | one strongest peak remains; V6 coverage passes; no accidental single-character display line survives |
| Layout | 3 distinct wireframes respecting the locked visual priority | selected system preserves the Hero media contract and safe zones |
| Color | 3 applied token sets | contrast and media overlay tested |
| Media | role map + local asset contract + frame review | 3 distinct videos; an off-target Hero is regenerated rather than contained |
| Components | every module has a content job | no decorative proof/card/module by default |
| Motion | motion hierarchy | motion communicates state or atmosphere; reduced version exists |
| Responsive | breakpoint transformations | no arbitrary mobile cropping or overlap |
| Synthesis | closed page plan | every section is implementable without guessing |
| QA | section + full-page desktop/phone screenshots, mechanical report, baseline comparison | visual-finish gate passes; no blocker/major or locked visual regression remains |

## Decision hierarchy

When rules conflict, use this order:

1. Explicit user requirement.
2. User-approved regression baseline and locked Hero contract.
3. Real content and factual constraints.
4. Accessibility and safe-zone protection.
5. Selected art direction and its token system.
6. A generated asset's accidental focal geometry.
7. Template/reference pattern.
8. Generic best practice.

A failed generated frame is replaceable evidence, not authority to overturn the locked visual priority.
