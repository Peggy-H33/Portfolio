# 花体、手写与高个性展示字体

本文件只说明高个性字体进入网页模块后的使用边界。逐字体的风格主题与适用模块见 `chinese-font-library.md`；不要从本文件推导固定组合。

## 先决定模块是否需要个性峰值

适合测试高个性字体的模块：

- `brand_mark`：2–6 字品牌名或识别短语；
- `hero_display`：2–12 字主命题；
- `editorial_quote`：作者题词、歌词、诗句或态度短语；
- `poster_badge`：短标签、活动口号或少量贴纸；
- `section_heading`：长页中少数需要转调的章节。

通常不适合：`body_longform`、`nav_ui`、`form_control`、法律说明、关键价格和安全信息。是否使用由模块任务决定，不要求花体和某款正文绑定。

## 必须做真实候选实验

用户提出“花体、手写、行草、书法、题字”时，至少在一个高影响模块测试两款真实加载的书写型字体；得意黑、龙珠体、无界黑、圆体和像素字只能作非书写对照，不能算花体候选。用户只提出“不正经、摇滚、时装、实验、可爱、海报冲击”时，至少测试多个轮廓不同的高个性类别。实验必须：

1. 使用页面真实文字；
2. 加载字体文件并用 `document.fonts.check()` 验证；
3. 和两个轮廓不同的候选使用同一背景、容器和断点；
4. 同时比较字号、字距、行高、颜色、对齐、行数和媒体遮挡；
5. 记录最终采用或拒绝理由。

测试不等于在任何场景强制采用；但当用户明确要求“花体、手写、行草、书法”时，最终必须保留一个 `calligraphic` 或 `handwritten` 签名峰值。明确要求“不板正、摇滚、时装、实验、强视觉冲击”或默认表现型营销/编辑场景时，最终必须保留一个更宽泛的表现型峰值。只有具体的可读性、字形覆盖、主题冲突或授权证据以及用户认可才能例外，且不得用 fallback 截图否决花体。

## 模块排版规则

- 花体标题优先 1–8 个汉字；超过两行先缩短文案。
- 手写和书法通常只有一个真实字重，设置 `font-synthesis: none`，不伪造 700 粗体或斜体。
- 中文花体不要默认 `letter-spacing: -0.06em`；从 `0` 开始，用容器、字号和手动断行调节。
- 细笔画放在高对比、低复杂度背景；复杂视频上提供独立文字安全区，不靠重遮罩救可读性。
- 流动、行草、速度型字形沿内容动势偏置即可，不同时堆描边、故障、霓虹和倾斜。
- 像素字只按整数倍缩放，圆体和粗黑不要通过阴影伪造立体感。
- 同一屏只设一个主要字体焦点。其他文字可以由各自模块独立选择，但不能争抢注意力。
- 签名字体要覆盖真实主句或主句的核心词；只给小 `<em>` 换花体而让最大中文仍是中性黑体，不算完成。
- 字体适配只能发生在文字安全区内，不得缩小全屏视频、移动媒体焦点或改变页面网格。
- 高个性字体缺字时换字体或拆分受控 fallback，不用日文字形静默补齐。

## 可访问性

- 草书、强笔触和作为图形使用的文字旁边提供可读的等价文本或 `aria-label`。
- 不把花体用作唯一的按钮标签、价格、时间、座位、表单错误和条款。
- 200% zoom 与 390px 下仍能识别，不出现孤字、遮挡主体或点击区变化。
- reduced motion 不得影响文本本身的可见性和语义。

## 自托管示例

```css
@font-face {
  font-family: "Page Hero Expressive";
  src: url("/fonts/selected-hero.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

[data-type-module="hero_display"] {
  font-family: "Page Hero Expressive", "Source Han Sans SC", sans-serif;
  font-synthesis: none;
  font-weight: 400;
  line-height: 1.04;
  letter-spacing: 0;
}
```

上例只展示该模块的 fallback，不暗示整页必须使用思源黑体，也不构成字体搭配建议。
