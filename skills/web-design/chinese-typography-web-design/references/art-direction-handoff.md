# 艺术方向接入合同

V6 是字体覆盖层，不是第二个网页生成 skill。

## 必需输入

- 现有页面或 `study/page-plan.json`；
- 锁定的 Hero 媒体模式、媒体边界、焦点区和 copy safe zone；
- 页面 section 顺序、主网格和断点；
- 允许使用的文字颜色 token；
- 真实中文文案与主要 Latin 字符串；
- 每个 section 可接受表现字体的 surface ID，以及必须保持安静阅读的 surface ID；不得预先写死字体家族；
- 代表性亮帧、暗帧和用户认可的基线截图。

## 输出边界

V6 只输出字体文件、许可证、`@font-face`、模块 type token、表现字体分布、字号、行高、字距、行宽、文字颜色、对齐、建议断行与有截图证据的局部文案几何调整。不得输出或覆盖 `page-plan.json`、媒体计划、页面架构、视频提示词、Hero CSS 或动效方案。

## 冲突处理

若字体在安全区内无法成立，依次：调整字重/字号/字距 → 换断行 → 换候选字体 → 缩短展示文案 → 向艺术指导 skill 提出建议。未经批准，不移动媒体、不缩小视频、不改变网格。
