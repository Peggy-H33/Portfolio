# 中文展示字与全局层级

## 一个最高峰值，多处分布

先选择一个最重要的中文模块作为 `signature_module`。它承担最强轮廓和情绪，但不是表现字体的唯一位置。再从章节标题、编辑引语、品牌标、短 CTA、导航短词、眉题、编号、图注首词或短导语中选出至少两个非 Hero 表达点。

适合营销、编辑、音乐、文化、作品集和消费品牌页面的候选实验：

1. 手写/行草/书法路线：作者性、速度、现场感或电影题词；
2. 实验黑体/动作海报/装饰宋体路线：现代轮廓、时装、工业、摇滚或视觉冲击；
3. 克制型对照：较稳的展示宋体、人文黑体或窄体，用于判断表现力是否过量。

普通表现型任务至少两个候选来自不同表现型类别。用户明确要求花体、手写、行草或书法时，改为至少两款不同的 `calligraphic`/`handwritten` 家族，再加入一款非书写型对照；实验黑体、动作海报字、圆体和像素字不能单独满足这一要求。

## 不把局部合理误当全局成功

- Hero、章节、引语和短功能文字可以独立选择，但完成后必须检查整页峰值分布。
- 不让同一展示字体以同字号、同对齐、同颜色重复统治所有章节。
- 不让最大 Latin 字把中文签名降为说明文字；需要双语时声明谁是第一视觉层级。
- 不把一个小范围 `<em>` 当作整页唯一花体证据。用户要求主要大字不板正时，签名字体必须覆盖真实主句或主句中的视觉核心词。

## 字体之外的参数

签名效果由字体、字号、行高、字距、颜色、行宽、对齐、断行和媒体关系共同产生。对每个候选分别调参，禁止用同一套 CSS 机械比较。

- 行草/手写：通常使用短句、较松字距或有意的负空间；可用于按钮、导航、图注或标签中的短语，但必须真实测试最终字号与交互状态。
- 动作/海报字：控制为 2–10 字，允许偏置或不对称，但不遮挡媒体主体。
- 清瘦展示字：只在对比稳定的背景上使用，亮/暗视频帧均需检查笔画。
- 装饰宋体：控制行数和标点，避免因“高级”自动用于所有大标题。

## 阅读保护而非固定中性角色

政务、医疗、安全、无障碍、密集数据、表单和关键交易以识别性优先。长段与关键操作默认使用清晰阅读字体；短标签、短 CTA、引语强调和非关键导航仍可提交表现候选，只要真实字号、状态、字符覆盖与 fallback 证据通过。
