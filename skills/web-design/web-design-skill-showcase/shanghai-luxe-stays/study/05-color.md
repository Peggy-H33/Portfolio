# Color lab

## Subject/material inputs

上海雨夜的墨色玻璃、石库门灰砖、旧饭店黄铜、旗袍丝绒、晨雾骨白、青瓷绿。

## Candidate A — 黑金饭店

- Tokens: #0c0d0c / #161714 / #eee7d7 / #c5a66a
- Applied preview: 高级但过度依赖金色。
- Video contrast: 暖帧上金字容易消失。
- Choose/reject: 拒绝作为完整系统，保留黄铜为小面积 accent。

## Candidate B — 青瓷晨雾

- Tokens: #10201b / #d9ded5 / #8fa69c / #f0eadc
- Applied preview: 生活方式感强，夜上海力度不足。
- Video contrast: 暗帧稳定，暖帧略显薄。
- Choose/reject: 作为中段恢复色与 focus 回声，不主导全页。

## Candidate C — 墨夜与旧金（选中）

- Tokens: ink #090a09 / charcoal #151714 / bone #ede6d8 / brass #c8a15d / celadon #7f988b / brick #5a3c34。
- Applied preview: 黑色媒体段与骨白编辑段交替，黄铜只出现在线、CTA、光晕和编号。
- Video contrast: 左侧局部线性 scrim 在最亮/最暗帧均保持正文可读，不覆盖右侧主体。
- Choose/reject: 选中；主题材料具体且能保留长页呼吸。

## Selected system

- Semantic tokens: canvas/ink #090a09；surface/bone #ede6d8；surface/moss #151b17；text-strong #f4eee2；text-dark #161714；muted #b7b0a3；accent #c8a15d；accent-2 #7f988b；line rgba(237,230,216,.22)。
- Lightest/darkest frame contrast result: 需在生成帧上复核；目标正文不低于 4.5:1，大标题不低于 3:1。
- Focus/hover result: 2px brass focus ring + 4px ink/bone outline gap；hover 仅移动箭头与反转底色，不依赖颜色表达动作。
- Full-page area budget: 中性与媒体材质 78%，高饱和平面 8%，其余为骨白恢复与低饱和青瓷。
