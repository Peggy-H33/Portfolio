# Brief and content

- Subject: 上海高端酒店与精品民宿的原创旅居策展页。
- Audience: 希望用 2–4 晚深入上海、重视空间审美与私密体验的情侣、独行者和小型家庭。
- Single page job: 让访客理解三种差异化的沪上高端住法，并发起一份非即时成交的旅程定制意向。
- Primary action: 打开“定制沪上住法”咨询对话框。
- Secondary action: 顺着页面探索三种住法。
- Content confidence: 采用原创虚构策展品牌和编辑性场景描述；不声称真实房价、奖项、星级或库存。
- Technical constraints: 原生 HTML/CSS/JS；本地字体、本地视频、本地海报；无需构建步骤；支持现代桌面与移动浏览器。
- Page density: narrative
- Dominant visual priority: 全屏动态酒店场景像一部上海夜行电影，中文命题是第一视觉层级。
- Hero media mode: cinematic-full-bleed
- Regression baseline source: none
- Protected visual qualities: 100vh 全屏媒体、左侧文案/右侧主体、稀疏导航、墨黑与暖金、非卡片化长页节奏。

## Narrative candidates

### A — 时刻叙事

城市初醒 → 午后退隐 → 夜色回家 → 定制行程。情绪连贯，但空间差异不够直接。

### B — 三种住法

电影化命题 → 城市节奏宣言 → 江岸高处 → 里弄私宅 → 海派客房 → 对比选择 → 雨夜夜床结尾 → 定制行动。空间选择清晰，适合页面主任务。

### C — 材质档案

黄铜、丝绒、灰砖、雨水、茶汽五种材料串联页面。美术性强，但容易弱化“酒店民宿”的明确主题。

## Selected structure and reason

选择 B，并把 A 的三段时间作为中段节奏轨。它让访客先被上海夜色吸引，再从三种真实可理解的空间原型中选择，不需要虚构数据证明。
