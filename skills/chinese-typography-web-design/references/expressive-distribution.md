# 表现字体分布合同

## 分布模式

- `distributed`：默认用于 landing、campaign、portfolio、音乐、文化、时装、消费科技和视觉型产品页。保留一个最强峰值，并让至少两个非 Hero surface 使用经过验证的表现字体。
- `concentrated`：用户明确只要一处题字、页面极短，或视觉基线要求单峰值时使用。不能因为省事自动选择。
- `restrained`：政务、医疗、应急、密集交易或用户明确不要表现字体时使用。

## 可表达的文字表面

不要把表现字体等同于“大标题字体”。逐项评估：

| 表面 | 可采用的表达方式 | 必查风险 |
| --- | --- | --- |
| Hero 主句 | 完整书写、题字、实验海报字 | 媒体主体遮挡、断行 |
| 章节标题 | 与 Hero 同家族的不同尺度，或第二表现家族 | 重复像多个 Hero |
| 引语/强调短句 | 行草、硬笔、日记感、编辑宋体 | 长句标点与手机换行 |
| 品牌标/栏目名 | 少字轮廓、签名、招牌感 | 小尺寸缺字与 Logo 冲突 |
| CTA 短语 | 手写动作词、展示字首词、双字体短句 | 动词识别、点击宽度 |
| 导航短词 | 克制手写/实验字形或当前项强调 | 10–14px 扫描和状态差异 |
| 眉题/徽标 | 贴纸、题签、窄体、像素或书写首词 | 字距过宽、全大写混排 |
| 图注/元数据 | 花体首词、作者署名、日期编号 | 低对比和过细笔画 |
| 数字/年份 | 表现数字或与中文题字混合 | 基线、等宽需求、单位 |
| 短正文/导语 | 温润手写、楷体或编辑字体 | 超过 2–3 行后的阅读灰度 |

长段正文、法律条款、输入内容、错误信息、价格确认和关键交易默认列入 `reading_protected_surface_ids`。默认保护不是永久禁令；若用户明确要求并且实际尺寸、字符覆盖、200% zoom、手机与 fallback 全部通过，可提交有证据的例外。

## 节奏而非次数上限

先标出每个 section 的“表达点”和“安静面”，再选择字体。允许同一书写字体跨多个 section 复现，也允许第二表现家族承担不同语义；不要规定“只能出现一次”。默认提交 2–4 个字体家族：一个阅读基底、一到两个表现家族、必要时一个数据/代码家族。

分布合格需要：

1. 一个明确的最高峰值；
2. 至少两个非 Hero 表现 surface；
3. 至少一个非大标题 surface，例如短 CTA、引语强调、品牌标、眉题、图注首词、导航短词或编号；
4. 相邻 section 不机械复制同一字号、颜色、位置和断行；
5. 每个小字号表现 surface 有 `legibility_checks`。

## 小字号表现字体证据

当 `visual_priority` 为 `reading` 或 `utility` 且字体类别为 calligraphic、handwritten、rounded-playful、impact-display 或 pixel-mono 时，记录：

```json
{
  "tested_css_sizes": ["12px", "14px"],
  "minimum_css_px": 12,
  "phone_verified": true,
  "zoom_200_verified": true,
  "bright_dark_verified": true,
  "fallback_verified": true,
  "result": "pass"
}
```

任何一项失败都不代表该角色永远不能用花体；先调整字号、字重、字距、颜色、短语长度或候选字体，再测试。
