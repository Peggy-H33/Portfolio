Each project will eventually follow this structure so reviewers can quickly understand its value and my contribution:

```text
Project context and objective
          ↓
User problem and core scenarios
          ↓
My role, product judgment, and key trade-offs
          ↓
Interaction flow and runnable demo
          ↓
Vibe-coding implementation approach
          ↓
Validation, limitations, and retrospective
```

| To be added | Planned format |
| --- | --- |
| Project context and objective | Concise case-study summary |
| Core interactions | Screenshots, screen recordings, or directly accessible demos |
| Personal role and decisions | Problem decomposition, solution choices, and trade-offs |
| Implementation process | AI tools, prompts / workflows, and necessary technical notes |
| Results and retrospective | Validation findings, known limitations, and next steps |
